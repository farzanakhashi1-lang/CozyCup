# CozyCup — Café Parisien

A little Parisian café in Astana. Final project for WEB Technologies 1 (Front End).

**Live website:** https://farzanakhashi1-lang.github.io/CozyCup/

## Pages
Accueil (home) · La Carte (Menu Book + Aroma Wheel) · L’Atelier (build a drink) · Réserver (table plan) · Cadeaux (gift cards) · Cart · Log in / Sign up · Profile · À propos

## Features
- Light / dark mode saved in localStorage
- Sign up, log in, profile, log out (demo — do not use a real password)
- Cart and favourites with counters, saved as JSON
- Form validation with messages under the fields
- jQuery effects and mouse effects (custom cursor, 3D tilt, parallax)
